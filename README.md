# Student Score Prediction App

## Project Overview
This is an **Education Technology (EdTech)** Machine Learning application designed to predict student exam performance based on their study habits. 

The goal of this project is to help educators and students understand the correlation between **study hours** and **academic results**, providing a data-driven approach to performance forecasting.

## Features
* **Data Analysis:** Explored a dataset of 6,000+ students to identify key performance factors.
* **Machine Learning:** Built a **Linear Regression** model using Scikit-Learn.
* **Interactive UI:** Developed a user-friendly web application using **Streamlit**.
* **Visualization:** Integrated dynamic charts to visualize the regression line and data spread.

## Technologies Used
* **Language:** Python 3.9+
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Deployment:** Streamlit

## Model Performance
* **Algorithm:** Linear Regression
* **Metrics:** Achieved a Mean Absolute Error (MAE) of ~2.44, providing reliable estimates within the dataset's range.
